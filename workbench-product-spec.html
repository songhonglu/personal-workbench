04 · 技术架构

极简技术栈，零依赖运行

纯前端 HTML/CSS/JS，无任何外部依赖，双端同源配置。

层面技术选型说明
结构HTML5单文件，语义化标签
样式CSS3 · CSS Variables · Flex/Grid所有颜色走 :root token，一处改色整站换肤
逻辑Vanilla JS (ES6+)无框架，无构建，直接运行
存储localStoragekey: workbench-v1，双端同 key 自动共享
同步可选轻量后端自托管，多设备实时共享（非必须）
图标内联 SVG无外部字体，无 CDN 依赖

双端文件结构

文件用途适配
workbench.html桌面版工作台侧栏导航 + 多列网格，min-width:1000px
workbench-m.html移动版工作台底栏 Tab + 浮动按钮，max-width:480px
workbench-deploy-v1.9.zip部署包双端文件 + 部署说明

数据流

05 · 使用场景

谁在用？怎么用？

从个人日常到团队协作，一个工作台覆盖多种场景。

🌅 晨间启动

打开工作台 → 查看今日概览环形 → 确认今日三件事 → 打卡早起、运动、阅读 → 开始一天。

📝 工作记录

任务完成后勾选 → 灵感随手记 → 下班前复盘今日完成度 → 调整明日计划。

💰 月度复盘

月底查看记账统计 → 分析支出构成 → 调整下月预算 → 更新长期目标进度。

📚 年度追踪

阅读页数、跑步公里、储蓄金额…年度目标进度条可视化，每周更新，年底复盘。

🍅 专注模式

番茄钟 25 分钟专注 → 连续作战 → 今日战绩可追溯，拒绝分心。

📱 双端同步

电脑上记任务 → 手机上打卡 → 同一份数据，同一份配置，无缝切换。
