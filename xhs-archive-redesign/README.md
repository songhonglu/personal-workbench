# 小红书归档站 · 重设计版

深色玻璃拟态风格的归档站点，零依赖单文件，直接替换 cowAgent 站点根目录文件即可。

## 文件清单

| 文件 | 用途 | 必须部署 |
|------|------|---------|
| `index.html` | 新版列表页（内置站内阅读器） | ✅ 替换服务器根目录的 `index.html` |
| `detail-template.html` | 新版详情页模板 | ⭕ 可选，供 cowAgent 以后生成详情页时套用 |
| `index.json` | 归档数据 | ❌ 不用动，服务器上已有 |

## 部署（1 分钟）

1. 把 `index.html` 上传到路由器 cowAgent 站点根目录，覆盖原 `index.html`：

```bash
scp index.html user@192.168.1.30:/path/to/cowAgent/site/index.html
```

（具体路径以 cowAgent 配置为准，就是现在提供 `http://192.168.1.30:8080/` 的那个目录）

2. 手机或电脑打开 `http://192.168.1.30:8080/` 即可。数据仍读取同目录的 `index.json`，QQ 机器人正常归档，页面自动更新。

## 本地预览

```bash
python3 -m http.server 8123
# 打开 http://localhost:8123/
```

注意：直接双击打开 `file://` 会被浏览器拦截 fetch，必须走 http。

## 新版列表页功能

- **数据自动增强**：从 slug 提取真实日期（原 `index.json` 只有年份）、清洗标题里的 `09 02` 前缀、自动打标签（36 条规则 + 中文关键词，81 条中仅 6 条未分类）
- **筛选体系**：搜索（`/` 快捷键）、排序（最新/最早/标题）、标签云、快捷筛选（全部/收藏/最近 30 天）、月度节奏图点击筛选
- **站内阅读器**：点击卡片右侧滑出阅读面板，展示元信息卡、标签、相关归档推荐、上一篇/下一篇导航——不再跳转到丑的旧详情页
- **收藏**：点星标收藏，存 localStorage（key: `xhs-favs`），可单独筛选查看
- **统计动效**：数字 countUp、标签分布渐变条、归档节奏柱状图、滚动 reveal、骨架屏
- **响应式**：桌面双栏（列表 + 侧栏），移动端单栏自适应，适配 safe-area

## 新版详情页模板（可选）

`detail-template.html` 供 cowAgent 以后生成详情页时替换旧模板。占位符见文件头部注释，未填充的字段会自动降级隐藏，不会出现裸露的 `{{TITLE}}`。

## 设计说明

- 主题：深色底 `#0a0a0f` + 小红书红渐变 `#ff2e55 → #ff7a45`，玻璃拟态卡片 + 噪点纹理 + 浮动 orb
- 字体：系统字体栈 + 等宽数字，无外部依赖
- 所有颜色走 `:root` token，改主题只动一处

## 关于「内容详细」的边界

当前 81 条归档的数据源里**没有正文**——原帖需要小红书登录，机器人只记录了标题和元信息（备注：`原文内容需要小红书登录才能访问`）。页面已把现有数据呈现到最好状态；若想让每篇真正详细，需要升级 cowAgent 的解析能力（登录态抓取或人工补充描述），把内容写进 `index.json` 的 `desc` 字段或详情页的 `{{CONTENT_HTML}}`，新页面/新模板都能直接承载。
