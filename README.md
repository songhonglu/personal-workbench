# 🌿 个人每日工作台

计划 · 打卡 · 目标 · 记账 · 笔记 —— 零依赖纯前端个人工作台，浏览器打开即用。

## 在线访问（统一入口）

**https://songhonglu.github.io/personal-workbench/** — 自动识别设备：手机进手机版，电脑进电脑版，并记住上次使用的页面与主题。

- 电脑版：`workbench-mint.html`（另有 mocha / rose / amber 三套配色）
- 手机版：`workbench-mint-m.html`（底栏 Tab + 抽屉导航 + 浮动按钮）

## 功能模块

| 模块 | 说明 |
|------|------|
| 今日计划 | 待办勾选 + P0/P1/P2 优先级 |
| 习惯打卡 | 热力图 + 连续天数统计 |
| 长期目标 | 进度环 + 目标进度卡 |
| 记账本 | 收支统计 + 月度支出构成 |
| 随手记 | 灵感 / 摘录 / 复盘 / 生活 |

仪表盘含今日概览环、置顶要事、快速记录、本周习惯追踪表、番茄钟、月度开销等 Bento 卡片。

## 数据说明

- 数据默认存浏览器 `localStorage`（key：`workbench-v1`），有同步 token 时本地缓存为 AES-GCM 密文（`ENC:v1`），泄露也读不出明文
- 左下角「导出备份」可导出 JSON；「导入恢复」可还原
- **多端同步（已默认开启，开箱即用）**：数据自动加密上云（Cloudflare 后端），手机 + 电脑用同一 token 即共享同一份数据；你的专属 token 已内嵌双端，打开页面即自动同步，无需任何设置
- 离线时保留加密本地缓存，联网后自动双向同步；详见 [同步使用说明.md](./同步使用说明.md)

```bash
# 仅局域网备用方案（不需要外网时）：手机电脑连同一 Wi-Fi，填同一局域网地址与令牌
node sync-server.js   # 默认端口 8788
```
